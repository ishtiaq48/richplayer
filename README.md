# RichPlayer Web

Offline music player for iPhone (installable web app).

**Open on iPhone in Safari:** https://ishtiaq48.github.io/richplayer/
then tap **••• › Share › View More › Add to Home Screen** (iOS 26), or **Share › Add to Home Screen** on older iOS.

- Songs you import stay on your iPhone (IndexedDB) and play fully offline
- Playlists, favorites, recently/most played, albums & artists, search & sort
- Queue, shuffle, repeat, 10-band equalizer, speed, sleep timer
- Lock screen / Control Center controls

No accounts, no tracking. Nothing is uploaded.
